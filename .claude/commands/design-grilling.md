# /design-grilling

Read `.claude/guidelines/design-grilling.md` — the single source for this practice — and apply it to the current task.

Key reminders:
- Ask the whole frontier in one numbered round, then stop and wait — never one question at a time.
- Every question carries your recommended answer, so the user can reply "1, 3, yes" and be done.
- Facts are yours to find (read the repo, dispatch a subagent); only genuine choices go to the user.
- Write each round's answers into the plan document as they land — the interview and the writing are one job.
- Done means the frontier is empty and the user confirms, not that the plan looks complete.
